### 📌 Featured Projects

- **[llm-caching-proxy](https://github.com/noorhusaan302-png/llm-caching-proxy)**  
  High-performance C HTTP proxy tailored for local LLM inference engines. Implements an event-driven I/O loop and a thread-safe LRU cache to eliminate redundant prompt compute and cut local token latency.

- **[ast-security-reviewer](https://github.com/noorhusaan302-png/ast-security-reviewer)**  
  Automated static security analysis engine and patch synthesizer written in Java. Parses Abstract Syntax Trees (AST) to detect code vulnerabilities and interfaces with on-device LLMs via Ollama (Qwen 2.5 Coder) for private, zero-leakage patch generation.

- **[enterprise-c-proxy](https://github.com/noorhusaan302-png/enterprise-c-proxy)**  
  High-concurrency, event-driven HTTP/HTTPS reverse proxy built in C. Engineered with BSD `kqueue` multiplexing, a POSIX thread pool, token bucket rate limiting, and an in-memory LRU cache.

- **[Noorshell](https://github.com/noorhusaan302-png/Noorshell)**  
  Custom POSIX Unix shell implemented from scratch in C. Features complete process lifecycle control (`fork`, `execvp`, non-blocking `waitpid` via `SIGCHLD`), file descriptor piping (`pipe`, `dup2`), I/O redirection, and custom built-in command handlers.
